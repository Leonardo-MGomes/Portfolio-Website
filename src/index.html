    Reason

    This website is a collaborative effort by Leonardo Miranda Gomes, me, myself and I.

    The reason for this website existing and why it is structured the way it is, is all dictated by my project assignment. That's right, this website is a school project that has no purpose other than to show my HTML and CSS skills to my teacher.

    Why only HTML and CSS? What about JavaScript or it's Frameworks?

    Good Question! I've been asking myself the same thing, and the answer is quite simple really. There is simply no reason to use JavaScript and would only make this project more complicated for absolutely no reason.

    First of all, JavaScript is not a requirement and therefore will not be marked/valued when grading, so adding it would make it more likely for me to lose points while not being able to get points. So it's no more than a lose-lose situation.
